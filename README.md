# Catalogue Dynasty 8

Site du catalogue (visites 360°). Hébergé gratuitement avec GitHub Pages.

- Le site se met à jour tout seul quand tu enregistres depuis le mode agent (lien « Espace agent » en bas de page).
- `data.json` contient les biens ; le dossier `media/` contient les images créées depuis le site.
- Ne mets jamais ta clé d'accès GitHub dans un fichier de ce dépôt.
